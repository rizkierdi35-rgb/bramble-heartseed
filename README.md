BRAMBLE is a twin-stick arena survival game: you are the thorn-warden of a garden, defending the glowing Heartseed at its centre from 10 waves of blight — swarming mites, ranged spitters, hulking brutes and the Hollow Root itself. Gather dew, level up, choose boons, and slay the boss to make the garden bloom again.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, aim with the mouse (thorns fire on their own), dash with SPACE, pause with P. No network, no build step — the game is plain static files under game/.
